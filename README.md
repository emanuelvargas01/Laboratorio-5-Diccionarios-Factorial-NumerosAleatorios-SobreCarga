# Laboratorio #5 Diccionarios, Factorial (Recursividad), SobreCarga de Metodos, Numeros Aleatorios
**Fecha:** [6/10/2026]

## Contenido del Repositorio
En este repositorio se contienen las diferentes soluciones de creacion de diccionarios. la implementación de recursividad al utilizar el factorial, la generación de numeros alteatorios utilizando el random, y la sobrecarga de metodos, la cual permite tener metodos con el mismo nombre que cambien un poco la funcionalidad segun la cantidad de parametros de entrada que este tenga.

## Tecnologías Utilizadas
* **Lenguaje:** C#
* **Entorno / Framework:** .NET FRAMEWORK
* **IDE / Editor:** Visual Studio 2026
* **Herramientas:** Git
